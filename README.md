## なぜ「ゲーム」なのか

普通のポモドーロタイマーは、休憩時間になっても**通知を無視できてしまいます**。
「あと少しだけ」で作業を続け、結局休まない。これが解こうとしている課題です。

ブレイクゲートは休憩を*お願い*しません。休憩時間になると、**ミニゲームが全画面で勝手に始まります**。
後ろでどんどん進んでいくゲームを見ると「ゲームをやらなければ」という焦燥感が生まれる——
**義務としての休憩を、内発的動機による休憩に変える**のが設計の中心にあるアイデアです。

> 「休憩を直接的に促すのではなくて、後ろでどんどん進んでいくゲームを見て
> 『ゲームをやらなければ』という焦燥感と内発的動機を生み出すデザインがすごい！」
> — 湯村翼さん（ProtoPedia コメントより）

さらに、休憩の**終わり際**にも仕掛けがあります。残り1分になるとゲーム画面が
徐々に透明（不透明度 1.0 → 0.1）になり、下の作業画面が透けて見えてきます。
ブツ切りに終わらせるのではなく、**自然に作業へ戻れるよう誘導**します。

## 休憩中のモード

| モード | 内容 |
| --- | --- |
| 🎵 **音楽ゲーム** | MIDIリズムゲーム。`.mid` から自動で譜面を生成し、4レーン（**D / F / J / K**）で遊ぶ |
| 🧱 **テトリス** | 40ライン消しでクリア。ハイスコアは次回に引き継がれる |
| 📜 **スクリプト実行** | 任意の Python（`.py`）を休憩中に起動 |
| 🖥 **アプリ/EXE実行** | 任意の実行ファイルを休憩中に起動 |
| ⬜ **ホワイトアウト** | 画面を真っ白にして強制的に休む |

音ゲーとテトリスは**休憩時間が0になっても止まりません**。遊び続けられます。
一方スクリプト/アプリ実行は［休憩終了］ボタンで停止します。

## 全体の流れ

```
ランチャー起動
  └─[作業・休憩時間とモード選択]
       ├─ 作業時間・休憩時間を入力
       ├─ 「休憩終了1分前に画面を透明にするか」を選択
       └─ 休憩中のモードを選択
                 ↓
      作業タイマー開始（画面右上に MM:SS、常に最前面）
        ※ フォーカスは奪わないので裏で作業を続けられます
                 ↓ 作業時間が0
      ［休憩を開始する］ボタンが出現（押すタイミングは自由）
                 ↓
      休憩タイマー開始 ＋ 選んだモードが全画面で起動
                 ↓ 残り1分 → 画面がフェード（透明化ON時）
                 ↓ 休憩時間が0
      次のセッションへ（同じ時間 / 再入力 / 終了）
```

マルチモニタ環境では、ランチャーのある画面にゲームとタイマーを表示し、
**他のモニターは白く塗りつぶして**集中できるようにします。

## 使ってみる

### 実行ファイル版（Windows・Python不要）

[`bin/PomodoroApp.exe`](bin/PomodoroApp.exe) をダウンロードして実行します。

> ⚠️ **楽曲（`.mid`）はリポジトリに含まれていません**（権利の都合による）。
> exe と同じ階層に `music/` フォルダを作り、お手持ちの MIDI ファイルを入れてください。
> 詳細は [`source/music/README.md`](source/music/README.md) を参照。

### ソースから実行

```bash
git clone https://github.com/buroido/breakgate.git
cd breakgate/source
pip install -r requirements.txt
python main.py
```

音楽ゲームを遊ぶには、`source/music/` にお手持ちの `.mid` を入れてください（[置き方](source/music/README.md)）。

### exe をビルドする

```bash
cd source
pyinstaller PomodoroApp.spec
```

`dist/PomodoroApp.exe`（1ファイル形式・ウィンドウアプリ）が生成されます。

## 操作キー

**音楽ゲーム**（4レーン・左から順に）

| 左 | 中左 | 中右 | 右 |
| --- | --- | --- | --- |
| **D** | **F** | **J** | **K** |

判定は **Just**（緑）/ **Good**（黄）/ **Miss**（赤）の3段階。難易度 Easy / Normal / Hard はノーツ密度に影響します。

**テトリス**

| 移動 | 回転 | ソフトドロップ | ハードドロップ |
| --- | --- | --- | --- |
| **←** / **→** | **A**（左）/ **S**（右） | **↓** | **↑** |

## ⚠️ 注意事項

**「スクリプト実行」「アプリ/EXE実行」モード**では、［休憩終了］ボタンを押すと
**起動した処理（プロセス）が強制的に停止されます。**

中断してはいけない処理の実行中は、絶対に［休憩終了］ボタンを押さないでください。
（例：ファイルの保存・書き込み中、長時間の計算、通信・ダウンロード中 など）

これらのモードで処理を中断したことにより生じたいかなる不具合・データ損失・損害についても、
製作者は一切の責任を負いかねます。自己責任でご利用ください。
