# music フォルダ

リズムゲームで使う楽曲（`.mid` / `.midi`）をこのフォルダに置いてください。

**楽曲ファイルはリポジトリに含まれていません。**
権利関係の都合により、同梱していた楽曲は配布対象から外しています。
お好きな MIDI ファイルを各自ご用意ください。

## 置き方

- ソースから実行する場合 … `main.py` と同じ階層の `music/`（このフォルダ）
- exe を使う場合 … `PomodoroApp.exe` と同じ階層に `music/` を作って配置

ここに置いた `.mid` は、楽曲選択ダイアログの一覧に自動で表示されます。
一覧に出したくない曲や別の場所にあるファイルは、ダイアログの
［ファイルを追加…］からも直接読み込めます。

## MIDI ファイルの入手先

- 自作の MIDI（DAW や打ち込みソフトで書き出したもの）
- 権利上、再配布・利用が許可されているフリー MIDI 素材

譜面は MIDI の `note_on` イベントから自動生成されるため、
音符が入っている MIDI であれば基本的にどれでも遊べます。
