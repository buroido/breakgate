# ブレイクゲート（ポモドーロ + 休憩中ミニゲーム）— ソースコード

PyQt5 製のポモドーロタイマー常駐アプリです。作業タイマー終了後の「休憩時間」に、
ミニゲーム（MIDIリズムゲーム／テトリス）や任意スクリプト・アプリ実行、ホワイトアウトを
全画面で表示し、休憩を能動的に過ごせるようにします。

## 注意事項

- **「アプリ/EXE実行」モード**および**「スクリプト実行」モード**では、
  **［休憩終了］ボタンを押すと、起動した処理（プロセス）が強制的に停止されます。**
- **中断してはいけない処理の実行中は、絶対に［休憩終了］ボタンを押さないでください。**
  （例：ファイルの保存・書き込み中、長時間の計算、通信・ダウンロード中 など）
- これらのモードで処理を中断したことにより生じた**いかなる不具合・データ損失・損害についても、
  製作者は一切の責任を負いかねます。** 自己責任でご利用ください。

## 動作環境

- OS: Windows 10 / 11（メイン動作確認環境。macOS は一部対応）
- Python: 3.11
- 主要ライブラリ: PyQt5 / mido / pygame
- MIDIリズムゲームの音は OS の MIDI シンセ（Windows: Microsoft GS Wavetable Synth 等）を使用します。

## セットアップ

```bash
pip install -r requirements.txt
```

## 実行

```bash
python main.py
```

- 楽曲（`.mid`）は同梱の `music/` フォルダから自動／ダイアログで選択します。
  `main.py` と同じ階層に `music/` を置いてください。

## 実行ファイル（exe）のビルド

PyInstaller の設定ファイル `PomodoroApp.spec` を同梱しています。

```bash
pyinstaller PomodoroApp.spec
```

`dist/PomodoroApp.exe`（1ファイル形式・ウィンドウアプリ）が生成されます。
exe を配布・実行する際は、exe と同じ階層に `music/` フォルダを置いてください。

# 使い方（詳細）

実行ファイル版（`PomodoroApp.exe`）／ソース版（`python main.py`）のどちらも、
起動すると小さな**ランチャー画面**（「作業・休憩時間とモード選択」ボタン1つ）が開きます。

## 1. 全体の流れ

```
ランチャー起動
  └─[作業・休憩時間とモード選択]ボタン
       ├─ 作業時間（分）→（秒）を入力
       ├─ 休憩時間（分）→（秒）を入力
       ├─ 「休憩終了1分前に画面を透明にするか」を選択
       └─ 休憩中のモードを選択（必要ならファイル/楽曲も選択）
                 ↓
        作業タイマー開始（画面右上に MM:SS、常に最前面）
                 ↓ 作業時間が0になる
        [休憩を開始する]ボタンが出る
                 ↓ ボタンを押す
        休憩タイマー開始 ＋ 選んだモードが全画面で起動
                 ↓ 休憩残り1分（透明化ON時は画面がフェード）
                 ↓ 休憩時間が0になる
        ・ゲーム  : そのまま遊び続け可（[休憩終了]ボタンで戻る）
        ・他モード : [休憩終了]ボタンで停止
                 ↓
        次のセッション選択（同じ時間 / 再入力 / 終了）
```

## 2. セッションの設定（最初の入力）

「作業・休憩時間とモード選択」ボタンを押すと、大きめのダイアログが順に表示されます。

| 入力項目                          | 範囲                      | 既定値     |
| --------------------------------- | ------------------------- | ---------- |
| 作業時間（分）                    | 0〜180                    | 0          |
| 作業時間（秒）                    | 0〜59                     | 1          |
| 休憩時間（分）                    | 0〜180                    | 5          |
| 休憩時間（秒）                    | 0〜59                     | 0          |
| 休憩終了1分前に画面を透明にするか | 透明にする / 透明にしない | 透明にする |

- 各ダイアログで**キャンセル**を押すと、ランチャー画面に戻ります。
- 最後に「休憩中のモード」を選びます（次項）。

### モード選択

| モード         | 内容                              | 追加で選ぶもの                               |
| -------------- | --------------------------------- | -------------------------------------------- |
| 音楽ゲーム     | MIDIリズムゲーム                  | 楽曲・難易度・MIDI出力（楽曲選択ダイアログ） |
| テトリス       | テトリス                          | なし                                         |
| スクリプト実行 | 任意の Python(.py) を休憩中に起動 | `.py` ファイル                               |
| アプリ/EXE実行 | 任意の実行ファイルを休憩中に起動  | `.exe`（Win）/ `.app`（mac）                 |
| ホワイトアウト | 画面を真っ白にして強制的に休む    | なし                                         |

設定が終わると作業タイマーが始まり、ランチャー画面は隠れます。

## 3. タイマーと休憩の操作

- **作業タイマー**：画面**右上**に `MM:SS` で表示されます。常に最前面ですが、
  キーボードのフォーカスは奪わないので、裏で別の作業を続けられます。
- **作業時間が0**になると、右上に **［休憩を開始する］** ボタンが出ます。
  - 自分のタイミングで押せます（押すまでの超過時間はコンソールに記録）。
- ボタンを押すと**休憩タイマー**が始まり、選んだモードが**全画面**で起動します。
- **休憩残り1分**（透明化を「する」にした場合）：ゲーム画面が徐々に透明（不透明度1.0→0.1）になり、
  自然に作業へ戻れるよう促します。
- **休憩時間が0**になると：
  - **ゲーム（音ゲー/テトリス）**：すぐには止まらず、遊び続けられます。
  - **スクリプト/アプリ/EXE**：右上に **［休憩終了（実行中の処理を停止）］** ボタンが出ます。押すと起動した処理を停止します。
- 1セッション終了後、次の選択が出ます：**「同じ時間でもう一度」「時間を再入力」「終了」**。

> マルチモニタ環境では、ランチャーがある画面にゲームとタイマーを表示し、
> 他のモニターは白く塗りつぶして集中できるようにします。

## 4. 音楽ゲーム（MIDIリズムゲーム）

### 楽曲の選び方（楽曲選択ダイアログ）

- 左：曲リスト（同梱の `music/` 内の `.mid` / `.midi` を自動表示）。曲を**ダブルクリック**で確定。
- 右：
  - **難易度**：Easy / Normal / Hard
  - **MIDI 出力**：音を鳴らすデバイス（Windows は通常「Microsoft GS Wavetable Synth」）
  - **［ファイルを追加…］**：手持ちの `.mid` を追加で読み込み
  - **［決定］ / ［キャンセル］**

### 操作キー

4レーン制。判定ライン上でキーを押します。

| レーン | 左    | 中左  | 中右  | 右    |
| ------ | ----- | ----- | ----- | ----- |
| キー   | **D** | **F** | **J** | **K** |

### 判定とスコア

- **Just**（緑）：最も高精度。**Good**（黄）：やや甘い。**Miss**（赤）：外し or 圏外。
- 画面左上に **Combo / Just / Good / Miss** の数を表示。Miss でコンボが途切れます。
- 難易度はノーツの密度に影響します（密度の目安：Easy＝疎 / Normal＝中 / Hard＝密）。
- 選んだ MIDI ファイルをそのまま BGM として再生しながらプレイします。

> 音が出ないときは、楽曲選択ダイアログの「MIDI 出力」を別のデバイスに切り替えてください。

## 5. テトリス

### 操作キー

| 操作                           | キー  |
| ------------------------------ | ----- |
| 左へ移動                       | **←** |
| 右へ移動                       | **→** |
| 左回転                         | **A** |
| 右回転                         | **S** |
| ソフトドロップ（1マス下げる）  | **↓** |
| ハードドロップ（一気に落とす） | **↑** |

### ルール・スコア

- **40ライン**消すとゲームクリア。
- スコアは一度に消したライン数で決まり、`80 / 100 / 300 / 1200` ×（レベル+1）。
- 一定ライン数ごとにレベルが上がり（最大レベル9）、ブロックの**落下が速く**なります
  （初期500ms、レベルごとに約40msずつ短縮、最速100ms）。
- ハイスコアは `tetris_highscore.txt` に保存され、次回以降も引き継がれます。

## 6. その他のモード

- **スクリプト実行**：選んだ `.py` を休憩開始時に起動します。休憩終了ボタンで停止します。
- **アプリ/EXE実行**：選んだ実行ファイルを休憩開始時に起動します。休憩終了ボタンで停止します
  （Windows はプロセス終了、macOS は終了コマンドを送信）。
- **ホワイトアウト**：画面を真っ白にして、休憩中に作業画面を見えなくします（強制的に休む用）。

## 7. 終了方法

- ランチャー画面、またはタイマー／休憩ボタンの**×（閉じる）**を押すと、アプリ全体が終了します。
- 起動中のミニゲームや外部プロセスも、終了時にまとめて閉じます。

## 8. 困ったときは

| 症状                         | 対処                                                                                          |
| ---------------------------- | --------------------------------------------------------------------------------------------- |
| 音ゲーで音が出ない           | 楽曲選択の「MIDI 出力」を別デバイスに変更（Windows標準シンセを推奨）                          |
| 曲が一覧に出ない             | `music/` フォルダを exe / `main.py` と**同じ場所**に置く。または「ファイルを追加…」で直接指定 |
| ゲーム画面に入力できない     | 「休憩を開始する」を押した後にプレイ可能。タイマーは最前面のまま操作可                        |
| 休憩が終わってもゲームが続く | 仕様です（遊び続けられます）。終了したい場合は休憩終了ボタン／×で停止                         |

## ファイル構成

| ファイル              | 役割                                                             |
| --------------------- | ---------------------------------------------------------------- |
| `main.py`             | エントリーポイント。ポモドーロ本体・UI・各モード起動・画面制御   |
| `qt_midi_game.py`     | MIDIリズムゲーム（譜面生成・MIDI再生・判定・描画）               |
| `qt_tetris_game.py`   | テトリス（ブロック制御・ライン消去・スコア）                     |
| `midi_utils.py`       | MIDI出力デバイスの列挙・選択ユーティリティ                       |
| `xplatform_window.py` | クロスプラットフォームのウィンドウ制御（最前面・透過・全画面等） |
| `PomodoroApp.spec`    | PyInstaller ビルド設定                                           |
| `music/`              | リズムゲーム用の楽曲（.mid）                                     |
